### 14:03 — Phase 4 concept block, instalment 1 of 3 delivered (§1.7 step 1)

Delivered in chat, labelled CORE / DETAIL, everyday analogies first (memory
note; handoff §5), the Control Systems mapping offered as optional because it
is exact. No comprehension check (§1.4). Summary for revision:

- **Two ways to move information between positions.** Attention: every
  position scores every other (query·key → L × L grid → softmax weights →
  weighted average of values; Phase 2's 1, 0, 2 → 0.284, 0.140, 0.576 re-used).
  State-space model: one pass, carrying a fixed-size summary (the state)
  updated at each letter. Analogy: bank balance (fixed size, updated per
  transaction, cannot recover a single transaction) vs the full statement.
- **The update rule.** h_t = a·h_{t−1} + b·x_t, y_t = c·h_t; a = keep factor
  in (0, 1). Phase 2's EMA of the weights is a one-number instance
  (a = 0.9999). Worked on `GGGAAACCC` with x = "is it G?": at C7 (G3's
  partner) a = 0.5 leaves 0.11 of a 1.75 peak (leaked away over the loop);
  a = 0.9 leaves 1.78 but blurred. Memory ≈ 1/(1 − a) steps. Real layers run
  many states with different keep factors; one Mamba-2 layer at d = 384 holds
  98,304 state numbers (12 heads × 64 channels × 128).
- **Control Systems form (exact).** h′ = Ah + Bx, y = Ch + Dx; notation trap
  (textbook state x / input u ↔ Mamba's h / x); D = feedthrough; A forced
  negative (A = −exp(·)) → poles in the left half-plane, discrete keep factor
  a = e^{ΔA} inside the unit circle; Δ = step size (A = −1, Δ = 0.69 →
  a = 0.5), where instalment 2 starts.
- **Linear vs quadratic cost.** L steps vs L² pairs (256 → 65,536;
  1,024 → 1,048,576). Measured single block: 6.0 vs 3.8 ms at 256 (Mamba
  slower), 11.7 vs 21.7 at 1,024 (faster). Big-O describes growth, not the
  price at small L. At our cap, linear time buys no speed; every model gets
  the same steps and batches (P4), so any Mamba win must come from quality.
  Linear time would matter for the long RNAs cut in D-007.
- **Filter view.** With fixed a, b, c the model is an LTI filter: output =
  input convolved with the impulse response (1, 0.5, 0.25, …); check
  y_7 = 0.0625 + 0.03125 + 0.015625 = 0.109375, same as the recurrence.
  Analogy: a clap's fading echo. S4 trained this way (one big convolution).
  Weakness: every letter fades at the same rate, so the model cannot choose
  what to keep (e.g. pause forgetting across a loop). Fix = selection
  (instalment 2), which breaks the convolution trick → the scan.
- **First look at the question.** Grid: C7 looks straight at G3 in one hop.
  State: whatever C7 knows about G3 must survive A4–A6 inside one summary.
  Real partners can be 100+ letters apart.
