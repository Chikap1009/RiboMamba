## Specification and a correction before collection
docs/experiments/2026-09-27-competition-residual.md (commit c95b447), then Amendment 1:
r = -Delta ln Z contains the target's own weight, so r -> -a mechanically as P -> 1.
The learning target became c = -Delta ln Z_rest = Delta logit P - a; ranking by y equals
ranking by a + c exactly (tested). Trajectory evidence that c is rival competition, not
saturation: corr(a, c) -0.549 overall, -0.415 for parents with P < 0.01.
