### 12:42 — Phase 3 concept block delivered (§1.7 step 1)

Delivered in chat, marked CORE (must explain in an interview) vs DETAIL.
Summary for revision:

- **Honest evaluation = a testbench the design didn't write.** Six
  properties: measures what matters; has a scale (real / shuffled / random
  reference points); can't be won by a trivial cheat; has error bars; fixed
  before results; not dependent on one instrument. The "trivial cheat"
  table: low MFE ← GC-rich random; novelty and diversity ← random letters;
  quality ← copying training RNA; letter statistics ← a 4-mer counter; MFE
  match ← flimsy designs; post-hoc metric ← any model; one oracle ←
  exploiting it. Metrics cover each other's blind spots.
- **Two settings.** Unconditional (Phases 2, 4: the sequence's *own* MFE
  structure plays the target) and design (Phase 5: a given target). Both
  built and tested now; design target sets frozen now, used in Phase 5.
- **MFE match** stays (the field's standard) but never alone.
- **Ensemble measures.** P(target) = e^(−ΔG/RT)/Z; fine for hairpins, near
  zero at real lengths (table above): probability spreads over near-copies.
  **Ensemble defect** (NED) = expected fraction of nucleotides in the wrong
  state; graded (bit error rate vs frame error rate: 0.98¹⁰⁰ ≈ 0.13).
  Energy gap: meaningful for short hairpins, ≈ 0 at real lengths because
  the nearest rival is a one-pair variant.
- **Structure beyond chance.** Raw MFE rewards composition (GC-70 random:
  −26.0 but z = +1.46). z-score vs k dinucleotide shuffles isolates the
  arrangement. Population version = "beats its shuffle" share (54.6 % vs
  79.4 %, chance 50 %).
- **Novelty** (vs training) and **diversity** (within the generated set;
  clustering; Hamming distance for same-length designs); both maxed by
  random letters → report only with quality.
- **Distributions, not means**; distances (Wasserstein-1, JSD) need
  calibration: real-vs-real floor, train-vs-held-out family shift,
  shuffled/random ceiling. Report against train and held-out references.
- **Temperature** = logits/T = Boltzmann with energy −logit (same maths as
  Phase 0). **Steps**: ≈ L/N letters revealed at once, which can't
  coordinate; beyond N ≈ L mostly wasted compute. Report a
  quality–diversity curve; choose the operating point by a pre-registered
  rule applied identically to every backbone.
- **Statistics.** Bootstrap CIs; cluster bootstrap by family for real
  held-out sequences; sampling vs training-seed randomness (die vs process);
  paired comparisons (common-mode rejection); multiple comparisons (64 % for
  20 tests) → few primary endpoints + Holm–Bonferroni.
- **Pre-registration**: list of what gets frozen; garden of forking paths
  (150 possible headline numbers); amendments only dated and under the
  D-011 conditions; frozen before Mamba exists.
- **Second oracle**: Goodhart; EternaFold (learned from Eterna
  chemical-mapping data, different model class, not kcal/mol → compare
  structure-level metrics only); steer/select with ViennaRNA, report under
  both; both still share blind spots (no pseudoknots, secondary only).
  Alternatives: RNAstructure (Turner parameters again, less independent),
  CONTRAfold (predecessor), LinearPartition (faster algorithm, same models).
- **Targets for Phase 5**: (a) ViennaRNA MFE structures of one native
  sequence per held-out family (native = positive control; "oracle-shaped"
  risk); (b) bpRNA screened (train overlap by letters and structure,
  pseudoknots, non-canonical pairs, > 256 nt, non-ACGU); (c) Eterna100
  (optional, external comparability). Seeded selection rule, test targets
  built only after the freeze, checksums recorded.

### 12:50–13:09 — Build unit 1: folding metrics (`ribomamba/eval/folding.py`)

**What.** `fold_one(sequence, target=None, n_shuffles=50, seed)` folds once,
computes the partition function once, and returns: `mfe`, `mfe_structure`,
`mfe_per_nt`, `paired_fraction`, `p_mfe`, `ned_mfe`; with a target also
`mfe_match`, `bp_distance`, `p_target`, `ned_target`, `energy_gap`; with
shuffles `shuffle_mfe_mean/sd`, `mfe_z`, `beats_shuffles`. `fold_many`
runs it over a list in parallel and returns a polars table, one row per
sequence, in input order. `check_target` refuses targets the oracle could
never form (length mismatch, unbalanced, non-canonical pair, hairpin < 3)
instead of letting them score a silent 0. Oracle settings written out
explicitly in `model_details()`: 37 °C, dangles 2, lonely pairs allowed
(ViennaRNA defaults), `uniq_ML` for subopt.

**Choices (why this way).**
- `beats_shuffles` counts ties as half, so its expectation is exactly 0.5
  when letter order carries no structure (the Phase 2 version counted ties
  as losses, slightly below 50 % for short sequences).
- Energy gap: subopt in widening windows (0.5 → 4 kcal/mol), capped at
  4 kcal/mol (a rival that far away is > 600× less likely); computed before
  the partition function because subopt reuses the MFE tables.
- Per-sequence seeds `(seed, index)`: results identical whatever the number
  of processes (tested).
- `spawn` workers, not `fork`: the parent may hold polars threads or a CUDA
  context, and forking a multi-threaded process can deadlock.

**Tests** (`tests/test_folding.py`, 14): Phase 0 numbers (GGGAAACCC P =
0.5065, gap 0.20, MFE −1.20; GGGAAACCA P = 0.9386); gap sign for a non-MFE
target (−0.20, bp distance 5); **brute force**: every structure of a short
sequence enumerated by our own recursion, weighted with RNAeval energies,
P and NED computed from their definitions, compared with the partition
function (4 sequences + one non-MFE target); invalid targets raise; random
60-mers beat their own shuffles 0.5 ± 0.07 of the time (exchangeability);
serial = parallel, seeded. `pytest` → **49 passed**.

**Finding: ViennaRNA's d2 partition function vs RNAeval.** The brute-force
check matched to ~10⁻⁹ for 3 of 4 sequences but was off by 0.056 % for
GGGAAACCC. Every structure's probability was off by the *same* factor
(0.9994), so Z itself carried extra weight. Probing: it happens only with
dangles = 2 (never with dangles = 0), only for sequences whose last
nucleotide can pair (GGGAAACCC, AGGGAAACCC, GGAAACC; not GGGAAACCCA).
Forcing each structure with hard constraints and comparing pf-internal
energy to RNAeval: the four structures whose outer pair closes on the
**last** nucleotide but starts after position 1 (`.((....))`, `.(......)`,
`..(.....)`, `.((...).)`) are weighted 0.017 kcal/mol more favourably by the
partition function than RNAeval scores them. A boundary-case inconsistency
inside ViennaRNA 2.7.2, below the 0.1 kcal/mol resolution of the energy
tables. **Decision:** keep dangles = 2 (the standard default; changing the
oracle would cost comparability for a < 0.1 % effect); test tolerance
10⁻³; note it here. (Possible upstream bug report; not filed.)

### 13:10–13:14 — Build unit 2: statistics (`ribomamba/eval/stats.py`)

`bootstrap_ci` (vectorised percentile bootstrap, refuses NaN so undefined
values must be dropped explicitly); `cluster_bootstrap_ci` (resamples
groups; ratio form Σnum/Σden so it also gives nats per nucleotide);
`hierarchical_bootstrap` (resample training seeds, then samples within
each: returns replicates so two backbones can be differenced);
`paired_test` (mean difference + bootstrap CI + sign-flip permutation
p-value, exact enumeration for n ≤ 16); `holm` (adjusted p-values).
Why sign-flip rather than a t-test: it needs no normality assumption, and
under "no difference" each paired difference's sign is a fair coin, which is
exactly what it simulates.

Tests (10), all known answers: 546/1000 → interval matches the normal
formula (± 0.031); coverage ≈ 95 % over 300 simulated datasets (skewed
data, accepted 0.89–0.98); cluster vs naive width ratio = √10 for families
of 10 identical members; exact sign-flip p = 2/8 and 2/16; a +0.02 effect
hidden by item difficulty is found paired (p < 0.001) and missed unpaired;
false-alarm rate ≈ 5 % under no difference; hierarchical interval ≫ pooled
when seeds differ; Holm textbook example (0.01, 0.04, 0.03, 0.005 →
0.03, 0.06, 0.06, 0.02).
